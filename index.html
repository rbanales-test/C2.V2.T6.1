MIDI Postal Dispatcher Simulator

Objective: Master MIDI memory addressing (Bank Select CC 0, CC 32, and Program Change) to prevent the notorious latched bank error.

Instructions:

  1. Click Start Simulator to power on the multitimbral synthesizer.
  2. Remember the Postal Analogy: Bank Select is the Street Name (CC 0 & CC 32); Program Change is the House Number.
  3. Click on any data block in the pool to move it into the sequencer transmission slots, or click it inside a slot to send it back.
  4. Follow the 5 sequential missions to deliver presets accurately without latching obsolete banks.
